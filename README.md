# Hotel Online Reservation System – Java Console Application

The Hotel Online Reservation System is a console-based application developed using Core Java. This project simulates a basic hotel booking process where users can enter guest details, manage booking information, select room and bed preferences, and view a categorized food menu.

The application demonstrates the practical implementation of Java fundamentals, including object-oriented programming concepts, user input handling with the Scanner class, and control flow using switch-case statements. This project helped strengthen my understanding of Java basics and structured program design.
